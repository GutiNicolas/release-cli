# T-05: `github-release` uploads the manifest's assets

- **Roadmap:** ../ROADMAP.md · **Phase:** 2 · **Repo:** release-cli · **Base branch:** release/go-apps-p2 (PR targets it, not main) · **Branch:** feature/release-assets
- **Depends on:** T-04 integrated · **Model:** sonnet · **Review tier:** read

## Goal
The GitHub Release of a Go app carries the archives, `checksums.txt`, the installer and the formula, so people can
download and verify them.

## Scope
- Files: `github_release.py` (when `prior["go-build"]` is ok, upload every manifest artifact except the npm tgz
  with `gh release upload --clobber` after create; declare `dry_run: safe` and list the assets in dry-run), README.
- Out of scope: other build connectors (the manifest is the interface).

## Contract
Roadmap → Contracts (results). Resume reuses the release and re-uploads only missing assets. RC = pre-release (as today).

## Acceptance criteria (executable)
- [ ] With a fake `gh` on PATH: create then one upload per asset; resume uploads only the missing ones; dry-run calls no `gh` and lists them — `pytest tests/test_github_release.py -q`
- [ ] Without `go-build` in `prior` behaviour is unchanged — same file
- [ ] Lint and the full suite — `uvx ruff check . && uv run --with pytest pytest -q`
- [ ] Nothing private in the diff — `git diff origin/main --name-only | xargs grep -niEf <forbidden list from the brief>` finds nothing
- [ ] README section updated; tests follow the repo's test rules (realistic bugs, survive refactors)

## Result (filled by the worker)

- [x] Fake `gh` on PATH: create, then one `gh release upload --clobber` per asset (archives, `checksums.txt`, installer, formula; the npm tgz is skipped); a resume reuses the release and uploads only missing or size-mismatched assets; dry-run calls no `gh` and lists them: `pytest tests/test_github_release.py -q` passes (14 tests).
- [x] Without a `go-build` result in `prior` (or one that is not ok) nothing is uploaded and the result is as before: same file.
- [x] `uvx ruff check .` clean; full suite `uv run --with pytest pytest -q` passes locally.
- [x] Private-name/detection grep over my diff (`git diff HEAD`): nothing. (`git diff origin/main` also lists pre-existing roadmap/README lines from other tasks that name localci and the repo owner; none are mine.)
- [x] README `github-release` section updated; four new behavior tests (create+upload+resume, size mismatch, no-go-build, missing file on disk) plus dry-run.

Decisions inside the spec: the connector answers `dry_run: "safe"` always (with no manifest the dry-run just reports it would create the release). Result on success adds `"assets"` (all names on the release) and `"uploaded"` (sent this run). A manifest file missing from `dir` fails the connector before any `gh` call. Open for integration: the connector uploads what `artifacts` lists when it runs. Today `go-build` lists only archives and `checksums.txt`; the installer and formula are rendered by T-07 (`homebrew-tap`), which the Order puts after `github-release`, so they reach the release only if T-07 (or go-build) writes them into `dir` and `artifacts` before `github-release` runs. No code change is needed here either way. `manifest.json` itself is not uploaded.
