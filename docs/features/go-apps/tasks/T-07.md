# T-07: `homebrew-tap` connector and install script

- **Roadmap:** ../ROADMAP.md · **Phase:** 2 · **Repo:** release-cli · **Base branch:** release/go-apps-p2 (PR targets it, not main) · **Branch:** feature/homebrew-install
- **Depends on:** T-04 integrated · **Model:** sonnet · **Review tier:** read

## Goal
`brew install <owner>/tap/<binary>` and `curl -fsSL <release url>/install.sh | sh` install a final release, checking
the checksum.

## Scope
- Files: new `release_cli/homebrew_tap.py` (built-in, declares `dry_run: safe`), `go_build.py` (render `install.sh`
  from a template in `release_cli/templates/` into the manifest), README.
- Formula: url and sha256 per os/arch from the manifest, `bin.install`, a `test do` running `<binary> version`.
  Finals only (an RC → skipped with a reason). Publishes by committing `Formula/<binary>.rb` to the tap with the
  GitHub API through `gh api` and the `token_secret`.
- `install.sh`: POSIX sh; detects os/arch; `VERSION` and `PREFIX` overridable; downloads the archive and
  `checksums.txt`; verifies with `sha256sum` or `shasum -a 256`; refuses on mismatch.
