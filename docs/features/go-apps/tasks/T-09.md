# T-09: localci releases with release-cli (acceptance)

- **Roadmap:** ../ROADMAP.md · **Phase:** 4 · **Repo:** localci · **Base branch:** release/go-apps-p4 (PR targets it, not main) · **Branch:** build/release-cli
- **Depends on:** release-cli phase 3 merged · **Model:** sonnet · **Review tier:** read

Base branch: localci's phase 4 release branch (its own plan decides; this task replaces the GoReleaser part of
localci's T-22). **Ships as localci's T-22** (user, 2026-11-23): no separate worker; T-22's worker meets these
criteria and its Result answers them. Public repo: fixtures use `acme/*`; run localci's forbidden-names grep before every push.

## Goal
localci's releases are cut with `release -rc` / `-fv`, and a dry-run produces every artifact a launch needs.

## Scope
- Files: `VERSION` (`0.1.0-SNAPSHOT`), `release.toml` (Roadmap → Contracts, with `main = "./cmd/localci"`, `package_dir = "packages/playwright"`,
  the tap and npm name the user chose, `[connectors.sign]`), `cosign.pub` (the user generates the key pair; the private key never enters the repo), `.gitignore` (`dist/`), `cmd/localci/main.go` or `version.go` (version from
  `debug.ReadBuildInfo` when `version == "dev"`), `Makefile` `build` unchanged.
- Out of scope: CI workflow beyond the example (localci's T-22), publishing the repo.

## Acceptance criteria (executable)
- [ ] `release --dry-run -rc --defaults --json` exits 0 and `dry_run_dir` holds `localci_<v>_{darwin,linux}_{amd64,arm64}.tar.gz`, `checksums.txt`, `localci-playwright-<v>.tgz` (or the chosen name), `localci.rb`, `install.sh`, `manifest.json`, `checksums.txt.sig`, `localci_<v>.intoto.jsonl`, `cosign.pub`; `shasum -a 256 -c checksums.txt` passes there — run it
- [ ] The host archive's `localci version` prints `<v>`; `localci serve` starts and the dashboard page loads (embedded templates and static files present) — run it
- [ ] The signature and provenance verify with the committed `cosign.pub` (README of T-08 commands) — run them
- [ ] A release run in localci's local CI (no GitHub Actions) with the key from its secrets signs the artifacts — run it once with `--dry-run`
- [ ] `go install ./cmd/localci` then `localci version` prints a version, not `dev` — run it
- [ ] `go vet ./... && go test ./...` and `npm test -w packages/playwright` pass
- [ ] Forbidden-names grep over the diff finds nothing
