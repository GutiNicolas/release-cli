# T-04: `go-build` connector and Go fixture

- **Roadmap:** ../ROADMAP.md · **Phase:** 2 · **Repo:** release-cli · **Base branch:** release/go-apps-p2 (PR targets it, not main) · **Branch:** feature/go-build
- **Depends on:** T-03 integrated · **Model:** sonnet · **Review tier:** read

## Goal
After the push (or in a dry-run), the binaries of every target exist as archives with checksums and a manifest,
built from exactly the tagged commit, with the version stamped in.

## Scope
- Files: new `release_cli/go_build.py` (built-in, entry point `go-build`, declares `dry_run: safe`), README
  section, `tests/fixtures/go-app/` (module `example.com/acme/hello`: `cmd/hello` with `var version = "dev"`,
  a `//go:embed` file, `VERSION`, LICENSE, README, `packages/hello-js/package.json`), `.github/workflows/test.yml` (add
  `actions/setup-go` to the Linux pytest job).
- Builds in a temporary `git worktree` at the tag (dry-run: at HEAD) so local changes never get in; removes it after.
- Out of scope: uploading (T-05), npm (T-06), formula and installer (T-07).

## Contract
Roadmap → Contracts (config `[connectors.go-build]`, Layout, `manifest.json`). Refuses when `dist/` is not
git-ignored (real run), when `go` is missing, or when a target fails (no partial manifest).

## Acceptance criteria (executable)
- [ ] Dry-run on the fixture produces 4 archives, `checksums.txt` and `manifest.json` matching the Layout; each checksum verifies (`shasum -a 256 -c`) — `pytest tests/test_go_build.py -q`
- [ ] The host-target binary prints the planned version (`hello version` → `0.1.0-rc0`), and its embedded file — same file
- [ ] A dirty working tree does not change the artifacts (built from the tag) — same file
- [ ] `go` missing → failed with the install hint; a target that does not compile → failed, no manifest — same file
- [ ] CI runs these tests (Go set up) — the PR's `test` workflow
- [ ] Lint and the full suite — `uvx ruff check . && uv run --with pytest pytest -q`
- [ ] Nothing private in the diff — `git diff origin/main --name-only | xargs grep -niEf <forbidden list from the brief>` finds nothing
- [ ] README section updated; tests follow the repo's test rules (realistic bugs, survive refactors)
