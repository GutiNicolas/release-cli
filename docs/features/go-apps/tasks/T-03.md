# T-03: Dry-run runs connectors that declare it safe

- **Roadmap:** ../ROADMAP.md · **Phase:** 2 · **Repo:** release-cli · **Base branch:** release/go-apps-p2 (PR targets it, not main) · **Branch:** feature/dry-run-connectors
- **Depends on:** phase 1 merged · **Model:** sonnet · **Review tier:** read

## Goal
`release --dry-run` can show the real artifacts: a connector that says it is safe runs in dry-run with
`dry_run: true` and an output folder, and its result reaches the next connector, while nothing is tagged,
pushed or published.

## Scope
- Files: `connectors.py` (`questions` answer accepts `"dry_run": "safe"`; request adds `out_dir`), `cli.py`
  (dry-run: after the existing checks, run safe connectors in order into `<tmp>/release-dry-run/<repo>/<version>/`,
  print it, `--json` adds `dry_run_dir` and `connectors`), README "Writing a connector",
  `tests/fixtures/fake_connector.py`.
- Out of scope: any real connector (T-04 to T-07).

## Contract
Roadmap → Decisions (dry-run builds). In dry-run, `sha` is HEAD and `tags` are the planned ones (not on origin).
Connectors without the flag behave as today. No run state is saved for a dry-run. A failure exits 1.

## Acceptance criteria (executable)
- [ ] A safe fake connector runs in dry-run, writes into `out_dir`, and the next safe one sees its result in `prior`; an unsafe one only asks — `pytest tests/test_connectors_contract.py -q`
- [ ] Dry-run saves no run state and creates no tag — `pytest tests/test_tag_boundary.py -q`
- [ ] Lint and the full suite — `uvx ruff check . && uv run --with pytest pytest -q`
- [ ] Nothing private in the diff — `git diff origin/main --name-only | xargs grep -niEf <forbidden list from the brief>` finds nothing
- [ ] README section updated; tests follow the repo's test rules (realistic bugs, survive refactors)
